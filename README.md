 🤖 Телеграм-бот для записи.

Бот для автоматизации записи клиентов, отправки вопросов и напоминаний о записи.

## 📋 Возможности

- 📅 Запись на услуги (имя, телефон, дата, время)
- 💬 Отправка вопросов администратору в личные сообщения
- 🔔 Автоматические напоминания за день до записи
- 📋 Меню с услугами, контактами, отзывами и кейсами
- ❌ Отмена записи в любой момент

## 🛠️ Стек технологий

- Python 3.11
- pyTelegramBotAPI
- SQLite
- python-dotenv
- APScheduler
